# homebrew-trrek

The Homebrew tap for [trrek](https://github.com/burakseyitkara1/trrek), a macOS menu bar app that turns the edges of the trackpad into single-finger controls.

```sh
brew install --cask burakseyitkara1/trrek/trrek
```

Requires macOS 26 or later on a Mac with Apple silicon. trrek keeps itself up to date after it is installed.
